**how i made it:**
this game was made in unity, unity HDRP to be precise. i used HDRP because of bloom, and better lighting quality.

this game started out as a untextures sphere as the earth, and a plain cube falling into the atmosphere using PARTICLES. 

thats right. there wernt any meshes when this game started. and i was messingaround with those particles for maybe 8 hours? 

i eventually realised that particles just wernt cutting it. 

i switched to meshes, and it looked much better! but i ran into another problem... 

the earth. right now, i had a basic unity sphere, scaled up to about 40000 size. 

and at that size, you could actually see THE INDIVIDUAL TRIANGLES in the sphere! and ontop of that, 

the texture i was using for the earth was some bland bluury earth texture, that wasnt even shiny!! and the

planet's atmosphere wasn't shiny, or nice and blue, no! so right then and there

i decided that i wasnt going to use the unity sphere, at all. after some fiddling around,

in c# i managed to code myself a static blue sphere! with an actually nice looking atmosphere!

i really liked this, so i added a texture. yes, it isnt the best. but its better than nothing!

after that i made a small UI, the biggest problem i had was i wanted a spinning preveiw of all of the objects

in the selection menu, but it was very hard to code in because i had to add seperate heirarchy objects to make it work.

and this strained my crappy laptop. after the ui was finished, i realised i was missing somthing... i was missing music!!

the game had no music!! so i got an ai to make a soundtrack for me, as i was afraid of getting copywrighted or somthing

if i used someone elses music. anyway it turned out great!
